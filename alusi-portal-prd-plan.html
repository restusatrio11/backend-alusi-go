✨ Product Requirement Document (PRD)

Blueprint & Rencana Pembangunan Frontend Portal Publik ALUSI

Portal Terpadu Akses Layanan & Katalog Aplikasi Terintegrasi Badan Pusat Statistik Provinsi Sumatera Utara.

Target Pengguna

Internal BPS & Eksternal Publik

Pegawai BPS Sumut, Satker Kab/Kota, Pemda/OPD, Peneliti & Mahasiswa.

Arsitektur Integrasi

REST API + SSE Streaming

Berbasis Go Gin RESTful Backend dengan Live Status Monitoring & AI Assistant.

Standar Desain

Modern Government-Tech

Kecepatan kilat, aksesibilitas WCAG 2.2 AA, Command Palette Cmd+K & Responsif.

🎯 Visi Produk

Pemisahan Portal Pengguna vs Admin Panel

Berbeda dengan Admin Panel yang fokus pada manajemen CRUD & analitik internal, Portal Publik dirancang sebagai single launchpad yang cepat, intuitif, dan ramah pengguna.

🌐 Portal Publik ALUSI (Fokus Utama)

  • Omnibox Search (Cmd+K): Pencarian instan fuzzy katalog aplikasi & panduan operasional.
  • AI Asisten Cerdas: Tanya jawab kebutuhan statistik & rekomendasi aplikasi secara natural.
  • Quick Launcher: Modul favorit personal, riwayat akses terakhir, dan navigasi 1-klik.
  • Live Health Indicator: Indikator live status operasional sistem tanpa reload (via SSE).
  • Tiket Bantuan Terbuka: Pelaporan kendala dan pengajuan saran fitur langsung ke tim IT.

🔒 Admin & Executive Panel (Sudah Tersedia)

  • Manajemen Metadata Katalog, Kategori & Urutan Prioritas Aplikasi.
  • Manajemen Hak Akses Matriks RBAC (Role-Based Access Control).
  • Monitoring Kesehatan Probe Server & Broadcast Pengumuman Terjadwal.
  • Dasbor Analitik Eksekutif: DAU/MAU, ranking klik, dan ekspor laporan CSV/Excel.
  • Penanganan Respon Tiket Feedback dan Audit Trail Forensik.

🔌 API Integration 01

Katalog Aplikasi, Kategori & Fuzzy Search

Portal mengonsumsi API katalog publik dengan dukungan caching TanStack Query dan multi-parameter filtering.

Daftar Endpoint Terkait

GET /api/v1/categories

Memuat seluruh kelompok kategori aplikasi dan metadata ikon.

GET /api/v1/apps

Daftar aplikasi terfilter kategori, target pengguna, dan status aktif.

GET /api/v1/apps/search?q={query}

Pencarian cepat berbasis trigram similarity ranking nama/deskripsi.

GET /api/v1/apps/:slug/guides

Mengambil dokumen petunjuk teknis dan FAQ aplikasi.

Fitur UI Frontend

  • Instant Client Filtering: Kombinasi filter kategori & pencarian kata kunci dengan debounce 200ms.
  • Target Audience Badge: Penanda visual modul internal (Pegawai BPS) vs portal publik/eksternal.
  • App Guide Modal: Menampilkan petunjuk langkah kerja dan kontak PIC pengelola aplikasi.
  • App Card Micro-Interactions: Hover elevation, quick launch link, dan toggle favorit.
🤖 API Integration 02

AI Assistant: Rekomendasi Cerdas Natural Language

Fitur asisten kecerdasan buatan berbasis Gemini yang menjawab pertanyaan pengguna dan mengarahkan ke aplikasi yang tepat.

Endpoint & Payload API

POST /api/v1/ai/ask
// Request Payload:
{
  "prompt": "Bagaimana cara menginput data survei ubinan padi?"
}

// Response:
{
  "jawaban": "Untuk survei ubinan, gunakan modul SIMBATIK...",
  "rekomendasi_apps": [{ "id": 1, "nama": "SIMBATIK", "url": "..." }]
}

Pengalaman Antarmuka AI Chat

  • Spotlight AI Floating Bar: Input prompt dengan placeholder sugestif (contoh: "Mau cari data inflasi?", "Input dokumen dinas?").
  • Interactive Response Cards: Jawaban AI dilengkapi dengan tombol peluncur aplikasi rekomendasi langsung (1-click direct open).
  • Typing Streaming Animation: Memberikan visualisasi loading cerdas yang interaktif saat AI memproses jawaban.
  • Suggested Prompts Pills: Tombol chip rekomendasi pertanyaan populer bagi pengguna awam.
⭐ API Integration 03

Personalisasi Pengguna & Pelacakan Akses

Memberikan pengalaman terpersonalisasi untuk pegawai yang login, sekaligus mencatat metrik penggunaan secara asinkron.

1. Toggle Favorit

POST /api/v1/apps/:id/favorite

Memungkinkan pengguna menandai aplikasi harian mereka. Data disimpan di database dan di-cache lokal untuk akses instan.

2. Rekaman Klik Telemetri

POST /api/v1/apps/:id/click

Setiap peluncuran aplikasi mentrigger telemetri klik tanpa memperlambat pembukaan tab baru (background async fire-and-forget).

3. Riwayat Terakhir Diakses

GET /api/v1/users/me/recents

Menampilkan deretan 5 aplikasi terakhir yang dibuka pengguna untuk efisiensi alur kerja harian.

💡 Optimistic UI Update: Tombol bintang favorit langsung berubah status secara instan di sisi klien sebelum server merespon untuk menghilangkan latensi antarmuka.

📡 API Integration 04

Status Kesehatan Layanan & Realtime SSE

Transparansi status operasional server kepada publik dan notifikasi langsung jika ada layanan yang sedang dalam pemeliharaan.

Arsitektur SSE Streaming

GET /api/v1/services/realtime-status (SSE)

Koneksi HTTP Server-Sent Events persisten yang mem-push status perubahan kesehatan modul secara instan ke browser tanpa perlu polling berulang.

GET /api/v1/services/status

Snapshot ringkasan ketersediaan SLA 30 hari untuk widget status bar publik.

Representasi Visual di Frontend

  • Live Pulsing Indicators: Titik hijau (Normal), oranye (Kendala), kuning (Maintenance), merah (Down) pada setiap kartu aplikasi.
  • Toast System Alerts: Pop-up notifikasi otomatis ketika layanan penting mengalami gangguan operasional.
  • System Health Status Page: Halaman transparan SLA publik /status yang menampilkan riwayat uptime per aplikasi.
📢 API Integration 05

Papan Pengumuman & Tiket Bantuan (Feedback)

Saluran komunikasi dua arah antara tim pengembang IT BPS Sumut dengan seluruh pengguna portal.

Siaran Pengumuman (Broadcast)

GET /api/v1/announcements
  • Sticky Header Banner: Menampilkan jadwal rilis fitur baru, agenda survei nasional, atau pemeliharaan server.
  • Tipe Pengumuman Dinamis: info (biru), warning (kuning), urgent (merah), maintenance (oranye).
  • Dismissable Storage: Pengguna dapat menutup banner dan preferensi tersimpan di local storage.

Pengajuan Tiket Umpan Balik

POST /api/v1/feedbacks
  • Floating Helpdesk Button: Tombol bantuan melayang di pojok kanan bawah yang membuka modal pengaduan.
  • Kategori Laporan: Kendala teknis (Bug), Saran Pengembangan (Fitur), dan Permasalahan Data.
  • Feedback Confirmation: Menampilkan nomor tiket keluhan untuk tindak lanjut tim pengembang.
⚡ Teknologi & Performa

Modern Frontend Stack & Tooling

Dibangun dengan standar ekosistem React modern untuk menjamin ukuran bundle ultra-ringan, kecepatan render maksimal, dan kemudahan pemeliharaan.

⚛️

React 19 + Vite

Bundler berkecepatan tinggi dengan Hot Module Replacement (HMR) instan.

🔄

TanStack Query

Stale-While-Revalidate caching, auto-refetching, dan deduplication request API.

🎨

Tailwind v4 + Shadcn

Design system modular, dark/light theme, dan aksesibilitas ARIA bawaan.

✨

Framer Motion

Animasi transisi mikro yang mulus untuk launcher dialog dan category switching.

Target Performance: Lighthouse Score 98+ | FCP < 0.6s | LCP < 1.2s | Total Bundle Size < 150 KB (gzipped)
🧩 Desain Komponen

Daftar Komponen UI Utama (Atomic Breakdown)

Struktur komponen yang siap dibangun secara modular dan dapat digunakan kembali (reusable).

1. SearchOmniboxModal

Modal Command Palette Cmd+K dengan auto-complete instan, shortcut keyboard navigasi panah, filter kategori cepat, dan history pencarian.

2. AppLauncherCard

Kartu aplikasi dengan logo resmi teroptimasi, indikator live ping status, chip kategori, tombol favorite toggle, dan preview panduan.

3. AIAssistantDrawer

Slide-over interactive dialog dengan input percakapan, rendering format Markdown jawaban, dan tautan aplikasi yang direkomendasikan.

4. QuickFavoritesBar

Grid horizontal aplikasi favorit berukuran compact dengan icon badge, khusus untuk peluncuran cepat tugas operasional harian pegawai.

5. StatusUptimeBadge

Komponen status realtime dengan visualisasi denyut (pulse) yang terkoneksi langsung ke stream Server-Sent Events (SSE).

6. FeedbackSubmitDialog

Formulir pelaporan kendala terintegrasi dengan validasi Zod, pemilihan modul bersangkutan, dan unggah tangkapan layar (opsional).

📱 Fitur Lanjutan

Aksesibilitas, PWA & Dukungan Offline

Memastikan portal dapat diakses oleh semua kalangan pegawai dan masyarakat dari beragam perangkat dan kondisi jaringan.

♿

WCAG 2.2 AA Compliance

  • Full Keyboard Navigation (Tab, Esc, Enter, Arrow keys).
  • Kontras warna tinggi untuk keterbacaan optimal.
  • ARIA labels semantik untuk pembaca layar (screen reader).
📲

Progressive Web App (PWA)

  • Dapat diinstall langsung ke Homescreen Smartphone & Desktop.
  • Service Worker caching untuk katalog aplikasi saat sinyal offline.
  • Tampilan responsif ramah layar sentuh mobile.
🌓

Dual Theme & Kustomisasi

  • Dukungan Dark Mode dan Light Mode otomatis.
  • Pilihan tata letak: Grid View vs List Table View.
  • Ukuran teks adaptif untuk kenyamanan mata.
